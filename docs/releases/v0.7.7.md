# v0.7.7 — Google Maps連携の安定化

## 地図・検索・徒歩経路

- Google公式のSDKローダーと型定義を使用し、地図・地点検索・徒歩経路を独立して読み込みます。経路やピンの読み込みだけが失敗しても、利用可能な地図は表示し続けます。
- SDK、地図タイル、地点の詳細、経路取得にタイムアウトを設け、再読み込み・再取得を追加しました。非同期の認証エラーも検知します。
- 番号付きピンと旅程の選択を同期し、「旅程全体を表示」と画面サイズ変更時の表示調整に対応しました。名前だけで追加した地点も、取得した経路が表示範囲に収まるよう調整します。
- 27地点を超える旅程はGoogleの上限に合わせて分割取得します。古い取得結果を表示せず、手入力した移動時間を維持します。
- 代替の位置関係図はGoogle Mapsではないことを明示しました。

## 接続設定の管理

- ブラウザー用キーをAWS Parameter StoreのSecureStringで暗号化管理し、開発・ビルド・デプロイ時に取得します。キーの値をGit管理対象のファイルやコンソール出力に含めません。
- 通常の `npm run deploy` も設定を取得し、キーがない状態で本番に反映することを防ぎます。`npm run check:maps` で設定を確認できます。
- ブラウザー用キーは配信コードから参照できるため、Google CloudのHTTPリファラー制限とAPI制限も併用します。

## 検証

- フロントエンド全132テスト成功。変更範囲の型検査とlintが成功しました。
- 実ブラウザーで地図、5地点のピン、徒歩経路、候補からの地点追加、ピンからの旅程選択、旅程切り替えを確認しました。
- 本番ドメインでのキー利用と、許可外ドメインでの拒否を確認しました。
