# v0.7.8 — 複数日・移動手段・共有（旅の余白アップグレード）

旅の余白（TripPlanner）の大型アップデートです。

## 追加・変更

- **移動手段の切り替え（徒歩／電車／車）**：区間ごとに移動手段を選べるようにしました。Google Routes APIで手段に応じた経路と所要時間を取得し（電車は区間ごとに取得）、手入力の時間は従来どおり優先します。地図下の外部リンクも手段に応じた経路リンクになります。
- **複数日対応＋日付**：旅に名前と出発日を設定でき、「日を追加」で複数日の旅程を組めます。日ごとにタイムラインと出発時刻を持ち、追加先の日を切り替えて場所を登録できます。予定の編集から日を移すこともできます。
- **複数の旅を保存・切り替え＋共有**：旅を複数保存して切り替えられるようにしました（従来の単一ドラフトは自動で移行します）。「共有リンクをコピー」で旅程入りのURLを共有でき、JSONの書き出し／読み込みにも対応しました。共有リンクとJSONには写真などの外部送信は含まれず、読み込む側で新しい旅として取り込みます。
- **.ics書き出し**：出発日を設定した旅程をカレンダー用ファイル（.ics）で書き出し、Googleカレンダーなどに読み込めるようにしました。
- **スポットにメモ・予約・費用**：各スポットにメモ・予約情報と費用を記録でき、合計費用をサマリーとしおりに表示します。
- **営業時間チェック**：候補検索で選んだ場所は営業時間（Google Places）も取り込み、到着予定が営業時間外・休業日の可能性がある場合に警告します。
- **天気連動の持ち物提案**：出発日と最初の地点から Open-Meteo の日別予報を取得し、「天気に合わせた持ち物を提案」で雨具・防寒・熱中症対策などを理由付きで持ち物候補に加えます。

## 内部

- ドラフト形式を拡張し、旧形式（v1）の保存データは読み込み時に移行します（検証つき）。
- 経路計算を `computeTripRoutes` に一般化し、手段ごとの分割取得に対応しました。従来の徒歩一括取得（`computeWalkingRoutes`）の挙動は維持しています。
- テストを追加しました（移行・共有・経路・ICS・営業時間・天気・複数日UI）。写真の永続化は今回含みません（アプリ化時に検討）。
