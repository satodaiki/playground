# v0.7.2 — 場所の入力・編集とスマホ表示の改善

## 修正

- 行きたい場所の入力欄に履歴と入力例の候補表示を追加しました。候補をタップして旅程へ追加でき、入力内容に合わせて絞り込めます。Google Maps未設定でも利用できます。
- 追加済みの場所を選び、「場所名」と「名前を変更」からリネームできるようにしました。変更した名前は自動保存されます。
- リネームしても滞在時間・手入力の移動時間・登録済みの座標を保持します。名前だけで追加した場所の訂正は、Google Mapsの検索先にも反映します。
- 地図上の表示名だけが変わった場合は、同じ経路を取得し直さず移動時間を保持します。
- スマホ右上の丸いロゴの傾きと配置を調整し、アイコンと文字が中央に収まるようにしました。
- 場所名の編集欄にも、iPhone Safariでの入力時の自動ズーム対策を適用しています。

## 検証

- 旅程の編集・保存・入力候補・地図連携の関連テスト43件成功。
- 通常ビルド成功。
- iPhone実機の表示・操作と、Google Mapsの実通信は未確認です。
