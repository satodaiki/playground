# v0.7.6 — 写真追加の形式・サイズ制限を撤廃

## 修正

- JPEG・PNG・WebPだけに限定していた写真追加の判定を削除しました。画像選択欄も、端末の画像全般を選べるようにしました。
- 1枚10MBの上限を削除しました。
- 形式情報が空の写真も、追加時に拒否しません。
- ブラウザーが実際に表示できなかった場合だけ、その写真を外して理由を表示します。他の写真は保持します。
- 画面と使い方から、形式・サイズの制約の案内を取り除きました。

画像を表示できる形式は利用するブラウザーに依存します。アプリによる形式の許可リストやファイルサイズ上限はありません。写真は外部に送信せず、再読み込み・旅程の切り替えまで保持します。残したいアルバムはPDFで保存してください。

## 検証

- しおりの関連テスト10件成功。SVG・HEIC・10MBを超える画像・形式情報のない画像が、追加段階で拒否されないことを確認しました。
- 複数追加・個別削除・印刷待ち・読み込み失敗時に他の写真が残ることも確認しました。
- 変更箇所のLintと通常ビルド成功。
- iPhone実機と、各形式の実ファイルを使った表示確認は未実施です。
