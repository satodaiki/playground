# v0.7.3 — Google Placesの候補検索に対応

## 変更

- 「行きたい場所」の入力欄にGoogle公式の候補検索を接続しました。都市名・駅・観光スポットなどで検索し、候補を選ぶと名前・住所・座標付きで旅程に追加します。
- 地図欄にあった検索を旅程の入力欄へ移し、地図や経路計算の成否とは独立して検索できるようにしました。
- 入力例・履歴を使った候補表示を終了しました。旅程と持ち物リストの自動保存は継続します。
- APIキー未設定時や検索エラー時は、入力文字を保って手入力で続けられます。接続時も「場所名だけで追加する」を選べます。
- 旅程を切り替えた後に古い検索結果が混ざることを防ぎ、選択した地点の座標・IDを検証してから追加します。
- スマホの検索欄にも16pxの文字サイズを設定しました。

## 利用に必要な設定

今回のデプロイ環境にはGoogle MapsのAPIキーが未設定のため、本番の候補検索はまだ有効になりません。手入力・旅程編集・Google Mapsへのリンクは利用できます。

Google CloudでMaps JavaScript API・Places API (New)・Routes APIと課金を有効にし、HTTPリファラーとAPIを制限したブラウザー用キーを `VITE_GOOGLE_MAPS_API_KEY` に設定して、再ビルド・デプロイすると有効になります。入力文字列はGoogleへ送信され、Google Maps Platformの利用料金が発生する場合があります。

[設定と使い方](https://github.com/satodaiki/playground/blob/v0.7.3/docs/trip-planner.md#google-maps)
