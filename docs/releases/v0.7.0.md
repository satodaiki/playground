# v0.7.0 — 旅程づくりと持ち物の準備

## 旅の余白（Trip Planner）

- 行きたい場所を並べ、滞在時間や順番、区間ごとの移動時間を調整できる旅程タイムラインを追加しました。
- 初回は空の旅程から開始します。「新しい旅程を作る」でやり直せ、金沢のサンプルは必要なときに開けます。編集中の内容を置き換える前に確認します。
- 旅先と目的を入力すると、旅に合う持ち物を提案します。スキーの板・リフト券、サーフィンのボードなど、目的に応じた道具を基本の持ち物に加えます。
- 持ち物の準備済みチェック、追加・削除、目的を変えての再提案に対応しました。共通項目のチェックと自分で追加したものは、再提案後も保持します。
- 旅程・出発時刻・手入力の移動時間・持ち物リストを、このブラウザーに自動保存します。
- Google Mapsを設定すると、地図での地点検索と徒歩経路・移動時間の取得が利用できます。未設定でも、場所名の追加と移動時間の手入力を利用できます。

持ち物の提案は入力キーワードと目的別リストに基づきます。最新の天気や現地情報は自動取得しないため、施設の備品・レンタル条件などに合わせて調整してください。

[旅行プランナーの使い方と設定](https://github.com/satodaiki/playground/blob/v0.7.0/docs/trip-planner.md)

## Subscription Scanner

- Gmailの請求・領収書メールからサブスクリプションを推定し、月額換算と年間の見直し余地を通貨別に表示する機能を追加しました。
- Google OAuth、Python Lambda、Terraformの構成を追加しました。既知サービスはルールで判定し、未判定の候補メールをOpenAI APIで解析します。
- 1回の走査上限を1,000件に拡張しました。

利用にはGoogle OAuth、OpenAI API、AWS Lambdaとフロントエンドの接続設定が必要です。[設定手順](https://github.com/satodaiki/playground/blob/v0.7.0/README.md)
