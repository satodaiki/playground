# v0.7.1 — iPhoneでの入力操作を改善

## 修正

- スマートフォン向け表示で入力欄の文字サイズを16pxにし、iPhone Safariでフォーカス時に起こる自動ズームを抑えるようにしました。
- 出発時刻・場所名・移動時間・旅先と目的・持ち物の追加入力を対象にしています。
- 大きな滞在時間の表示と、ピンチ操作によるページの拡大はそのまま利用できます。

## 検証

- 通常ビルド成功。
- iPhone実機での動作確認は未実施です。
