# v0.7.4 — 写真付きの旅のしおり

## 変更

- 旅程の操作欄に「しおり」ボタンを追加しました。旅程または持ち物がある状態で、印刷用のプレビューを開けます。
- 旅程の時刻・住所・滞在時間・徒歩移動と、準備済みのチェックを含む持ち物リストをA4縦向けに表示します。移動時間が未入力の場合は、しおりにも目安であることを明記します。
- 「写真を追加」で表紙に写真を1枚載せられます。差し替え・削除に対応し、画像の読み込み完了後に印刷できます。
- 「印刷・PDF保存」からブラウザーの印刷画面を開きます。編集用ボタンは印刷せず、内容に応じて複数ページに分けて出力します。
- プレビューを閉じて旅程を編集し、再び開いても写真を保持します。
- 海水浴（海・ビーチ）の持ち物候補に「ゴーグル」を追加しました。作成済みの持ち物リストは「持ち物を提案し直す」で更新できます。

## 写真について

JPEG・PNG・WebP形式、10MB以下の写真を利用できます。写真は外部へ送信せず、ブラウザー内で扱います。ページの再読み込みや旅程の切り替えで消えるため、その場合は写真を選び直してください。

[しおりの使い方](https://github.com/satodaiki/playground/blob/v0.7.4/docs/trip-planner.md#紙のしおりpdf)
